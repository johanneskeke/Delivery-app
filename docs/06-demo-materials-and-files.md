## 1. Synthetic tour (Step 1)
**Tour header:** tour KRZ-61-07 · date Thu 2026-11-26 · delivery district "Kreuzberg 61 (Bergmannkiez to Graefekiez)" · start and end: depot "Zustellbasis Tempelhof, Eresburgstraße 24, 12103 Berlin" · vehicle: van, 3 racks (A–C) with 4 slots each · shift start 07:30 · planned departure 08:30 · origin: synthetic test data for the M10 prototype; all names and companies invented, streets real; not a real carrier document.

**Content:** 95 shipments on 58 stops; products: 73 parcels (Paket), 17 small parcels (Päckchen), 2 bulky items (Sperrgut), 3 pickups/returns (Abholung (Retoure)); services: 7 preferred neighbour, 5 preferred drop-off spot, 4 priority by 12:00, 3 age check 18+, 1 ID check; 32 shipments with a time window (business opening hours); free-text notes (neighbour, drop-off place, access, e.g. "Kühlware zuerst, Lieferung über Seiteneingang", "Zugang über Hofeinfahrt").

**Columns (German, as in the files):** Stopp (system order) · Sendungsnummer (barcode content, prefix SYN = synthetic) · Empfänger · Straße · Hausnr. · Adresszusatz · PLZ · Ort · Produkt · Service · Zeitfenster von · Zeitfenster bis · Gewicht kg · Hinweis.

**System order:** postcode, then street alphabetically, then house number; deliberately not optimised.

**5 deliberate import errors:**
| Shipment | Stop | Error |
|---|---|---|
| SYN512414257 | 28 | typo in the street name ("Zossner Str.") |
| SYN488823240 | 9 | postcode missing |
| SYN488823240 | 9 | street abbreviated ("Bergmannstr.") |
| SYN954372961 | 56 | wrong postcode (Körtestraße 8 with 10961; correct 10967) |
| SYN430548958 | 24 | address addition inside the house number ("Solmsstraße 12 HH 3.OG") |

**Unintended:** 5 house numbers do not exist in OSM (see 02, open decision 4).

## 4a. App data bundle (data format v1, 2026-11-20)

| File | Content |
|---|---|

Not computed since the driver app redesign (2026-11-20): `if_rejected` per change (always null) and a march scenario.
Slots: rack by route position (A = first part, at the sliding door), same halt → same slot, halts with a parcel over 10 kg always in slots 1–2 (a bottom slot may hold a few more parcels; slots hold 4–13 parcels), bulky → floor, pickups → C4.

## 7. Running the scripts from the bundle
- Unzip, keep the folder structure (tourdaten/, probelauf/, data_*/, scripts/).
- `pip install shapely pyproj networkx matplotlib reportlab openpyxl` (zxing-cpp + Pillow only for barcode checks).
- Trial run: `python3 probelauf/bericht.py` then `python3 probelauf/karte.py` (paths are resolved relative to the bundle).
- Tour/PDF scripts: run inside `tourdaten/` (they read `tourliste.json`); PDFs need the Liberation fonts (`/usr/share/fonts/truetype/liberation/`).
